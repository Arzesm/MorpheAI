# 🌙 MorpheAI - Dream Journal & Meditation App

MorpheAI — это mobile-first PWA приложение для записи и анализа снов, медитаций и работы с подсознанием с использованием искусственного интеллекта.

## ✨ Особенности

- 📱 **Mobile-first дизайн** — оптимизировано для мобильных устройств
- 🌙 **Дневник снов** — запись, анализ и визуализация снов
- 🧘 **Медитации** — управляемые медитации и звуки природы
- 📚 **База знаний** — статьи о науке сна и практиках
- 💬 **AI Чат** — общение с MorpheAI для анализа снов
- 🌓 **Фазы луны** — отслеживание влияния луны на сны
- 📊 **Статистика** — анализ паттернов сна
- 🔮 **Архетипы** — работа с юнгианскими архетипами
- 📴 **Offline режим** — работа без интернета (PWA)

## 📱 Структура приложения

### Основные маршруты

- `/portal` — Главная страница
- `/journal` — Дневник снов
  - `/journal/new` — Запись нового сна
  - `/journal/[id]` — Детальная страница сна
- `/meditate` — Медитации
  - `/meditate/[id]` — Плеер медитации
- `/knowledge` — База знаний
  - `/knowledge/[id]` — Статья
- `/chat` — Чат с MorpheAI

## 🌐 PWA Функции

Приложение полностью поддерживает PWA:

- ✅ Установка на главный экран
- ✅ Offline режим
- ✅ Push-уведомления (готово к интеграции)
- ✅ Кэширование ресурсов
- ✅ Fullscreen режим

### Установка PWA

1. Откройте приложение в браузере (Chrome/Safari/Edge)
2. Нажмите "Установить приложение" в меню браузера
3. Приложение появится на главном экране

## 📝 Разработка

### Добавление новой страницы

1. Создайте директорию в `src/app/`
2. Добавьте `page.tsx` с компонентом
3. Обновите навигацию в `BottomNav.tsx` если нужно

### Добавление компонента

1. Создайте файл в `src/components/`
2. Используйте TypeScript для типизации props
3. Следуйте стилю существующих компонентов

### Стилизация

Используйте классы Tailwind с фирменными цветами:

\`\`\`tsx
<div className="bg-night-deep-blue text-mythic-ivory">
  <button className="btn-primary">Кнопка</button>
  <div className="card">Карточка</div>
</div>
\`\`\`
