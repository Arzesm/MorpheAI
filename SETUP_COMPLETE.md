## 🎯 Структура таблицы `dreams`:

```sql
- id (uuid)              - уникальный ID
- user_id (uuid)         - ID пользователя (пока NULL)
- title (text)           - название сна
- content (text)         - полное описание
- date (date)            - дата сна
- emotion (text)         - эмоция
- emotion_emoji (text)   - эмодзи
- tags (text[])          - массив тегов
- archetype (text)       - архетип
- dream_type (text)      - тип (normal/lucid/nightmare)
- has_interpretation     - есть интерпретация
- interpretation (jsonb) - JSON с интерпретацией
- has_image (boolean)    - есть изображение
- image_url (text)       - URL изображения
- created_at             - дата создания
- updated_at             - дата обновления
```

## 🔐 Безопасность:

**RLS включен**, но временно настроены открытые политики для тестирования:
- Все могут читать
- Все могут создавать
- Все могут обновлять
- Все могут удалять

**После добавления аутентификации** нужно будет изменить политики на:
```sql
using (auth.uid() = user_id)
```

## 🐛 Если что-то не работает:

### **Ошибка при установке @supabase/supabase-js**
```bash
# Попробуйте с флагом --force
npm install @supabase/supabase-js --force
```

### **SQL ошибка при создании таблиц**
- Проверьте, что скопировали весь код из `CREATE_TABLES.sql`
- Попробуйте выполнить по частям

### **Сны не загружаются**
- Откройте консоль браузера (F12)
- Проверьте Network → XHR запросы
- Убедитесь что таблица `dreams` создана в Supabase

### **401 Unauthorized**
- Проверьте `.env.local` - ключи должны быть скопированы полностью
- Перезапустите `npm run dev`
