Что нужно сделать:

  1. Откройте: Supabase Dashboard → Functions
  2. Нажмите "New Function"
  3. Имя функции: generate-dream-image
  4. Скопируйте код из файла:
    supabase/functions/generate-dream-image/index.ts
  5. Вставьте код в редактор
  6. Нажмите "Deploy"
  7. Подождите 10-30 секунд
  8. Вернитесь сюда и нажмите "Проверить статус" снова
