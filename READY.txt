  🎯  ЧТО ПРОИСХОДИТ ПРИ ГЕНЕРАЦИИ:
═══════════════════════════════════════════════════════════════════

  1. 🎨  Пользователь нажимает "Сгенерировать"
  2. 📤  Запрос отправляется в Edge Function
  3. 🧹  HTML очищается от тегов
  4. 📝  Создаётся промпт для DALL-E 3:
         "Create a photorealistic image based on this dream.
          DO NOT include any text. Make it look like a photograph."
  5. 🤖  Edge Function вызывает OpenAI DALL-E 3 API
  6. 🖼️  DALL-E 3 генерирует изображение (10-30 сек)
  7. 💾  URL изображения сохраняется в Supabase
  8. ✨  Изображение отображается пользователю
