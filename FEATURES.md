# ✨ Обзор функционала MorpheAI

## 🏠 Главная страница (/portal)

### Реализованные компоненты:

1. **Фаза Луны** (`MoonPhase.tsx`)
   - Отображение текущей фазы луны с emoji
   - Процент освещенности
   - Знак зодиака, в котором находится луна
   - Описание влияния на сны

2. **Архетип дня** (`ArchetypeOfDay.tsx`)
   - Определение доминирующего архетипа
   - Красивая градиентная карточка
   - Описание архетипа

3. **Статистика месяца** (`MonthlyStats.tsx`)
   - Количество записанных снов
   - Осознанные сновидения
   - Тревожные сны
   - Эмоциональный индекс (0-10)

4. **Календарь снов** (`DreamCalendar.tsx`)
   - Интерактивный календарь
   - Цветовая индикация типов снов
   - Легенда с объяснением цветов

5. **Последние сны** (`RecentDreams.tsx`)
   - Карточки последних 3 снов
   - Дата, эмоция, теги, архетип
   - Превью описания сна

6. **Рекомендованные статьи** (`RecommendedArticles.tsx`)
   - Подборка из базы знаний
   - Категория и время чтения

7. **Советы по улучшению сна** (`SleepTips.tsx`)
   - Полезные короткие карточки
   - Практические рекомендации

## 📖 Дневник снов (/journal)

### Основные страницы:

1. **Список снов** (`/journal`)
   - Поиск по снам
   - Фильтры (эмоции, типы, архетипы)
   - Карточки снов с превью
   - Индикаторы: интерпретация, изображение

2. **Запись нового сна** (`/journal/new`)
   - Текстовое описание
   - Кнопка записи голоса (готова к интеграции Whisper)
   - Выбор эмоции
   - Добавление тегов
   - Кнопки AI: интерпретация и генерация изображения

3. **Детали сна** (`/journal/[id]`)
   - Полное описание сна
   - Теги и архетип
   - AI интерпретация
   - Объяснение символов
   - Рекомендации
   - Сгенерированное изображение (место готово)
   - Кнопка обсуждения с MorpheAI

### Компоненты:

- **DreamCard** - карточка сна в списке
- **FilterModal** - модальное окно фильтров

### Фильтры:

- По эмоциям (7 вариантов)
- По типу сна (обычный, осознанный, кошмар, вещий)
- По архетипу (12 вариантов)
- Наличие интерпретации
- Наличие изображения

## 🧘 Медитации (/meditate)

### Реализовано:

1. **Управляемые медитации** (`/meditate`)
   - 4 готовые медитации
   - Длительность, описание
   - Красивые градиентные карточки

2. **Звуки природы**
   - 5 звуков (дождь, море, лес, ветер, белый шум)
   - Play/Pause управление
   - Готово к интеграции аудио

3. **Таймер выключения**
   - Модальное окно с настройкой
   - Предустановленные значения (5, 10, 15, 30, 45, 60 мин)
   - Слайдер для точной настройки

4. **Плеер медитации** (`/meditate/[id]`)
   - Большой play/pause контрол
   - Прогресс-бар
   - Этапы медитации
   - Таймер (текущее время / общее время)
   - Индикация текущего этапа

### Компоненты:

- **MeditationCard** - карточка медитации
- **SoundCard** - карточка звука природы
- **TimerModal** - таймер автовыключения

## 📚 База знаний (/knowledge)

### Функционал:

1. **Список статей** (`/knowledge`)
   - Поиск по заголовку и описанию
   - Фильтр по категориям (Все, Наука, Практика, Психология, Символы)
   - Секция "Популярное" (топ-3)
   - Индикаторы: просмотры, время чтения
   - Добавление в избранное

2. **Просмотр статьи** (`/knowledge/[id]`)
   - Полный текст статьи
   - Markdown-like форматирование
   - Метаданные: автор, дата, категория, просмотры
   - Кнопки: добавить в избранное, поделиться
   - Похожие статьи

### Компоненты:

- **ArticleCard** - карточка статьи

### Категории:

- 🧪 Наука о сне
- 🌙 Практики
- 🧠 Психология
- 🔮 Символы и архетипы

2. **DALL-E 3** (генерация изображений)

   - Визуализация снов
   - Кнопки в UI готовы

3. **Whisper** (распознавание речи)
   - Кнопка записи голоса

   - UI для записи
